# 🧫 Bio-Safe School IoT — PuraBox

Esterilizador inteligente para entornos educativos que utiliza luz germicida **UVC de 254 nm** para desinfectar periféricos compartidos como teclados y mouses.

El sistema combina un **Arduino Uno R3** con conectividad **WiFi via ESP8266**, controlado desde una app móvil que registra cada ciclo de desinfección y muestra métricas de ahorro ecológico y económico en tiempo real.

## 🔧 Tecnologías

* Arduino Uno R3 + ESP8266
* Android Studio (app móvil)
* Comunicación WiFi / HTTP
